# 🎮 Redmark Studio

A modern web-based game studio showcasing interactive browser games built with clean UI, smooth animations, and responsive design.  
Designed to work flawlessly on **PC, tablet, and mobile devices**.

🌐 **Live Website**  
👉 https://shreemarwadi.github.io/Redmark-Studios/

---

## ✨ About the Project

**Redmark Studio** is a personal web platform created to host and showcase browser-based games.  
The goal of this project is to combine **game logic**, **UI design**, and **performance-focused frontend development** into a single polished experience.

The platform is fully static and deployed using **GitHub Pages**, making it fast, lightweight, and easy to maintain.

---

## ♟️ Featured Game

### Royal Chess – Indian Classic
A fully playable chess game with:

- 🧠 Player vs AI and Player vs Player modes  
- 📱 Fully responsive layout (PC, tablet, mobile)  
- 👆 Touch-friendly controls for mobile devices  
- 🎨 Custom themed UI inspired by Indian classical design  
- ⚡ Smooth animations and move highlights  

The chess board dynamically adapts to different screen sizes and aspect ratios without layout breaks or zoom issues.

---

## 🛠️ Built With

- **HTML5** – semantic structure  
- **CSS3** – custom UI, animations, responsive design  
- **JavaScript (Vanilla)** – game logic and interactivity  
- **GitHub Pages** – hosting and deployment  

No frameworks. No libraries. Pure fundamentals.

---

## 📱 Responsive Design

- Optimized for **Android & iOS browsers**
- Handles different aspect ratios (16:9, 18:9, 20:9, etc.)
- No unwanted zoom or overflow issues
- Desktop layout remains unchanged
